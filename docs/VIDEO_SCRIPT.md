# Сценарій відео (≈ 6–7 хв)

Формат: **ЕКРАН** — що показувати, **КАЖУ** — текст. Цифри реальні, з повного прогону оцінки.

## Перед записом

1. Скинути базу:
   ```bash
   python -m hr_assistant.db --reset
   ```
2. Запустити сервер:
   ```bash
   python -m uvicorn app.server:app
   ```
3. Відкрити http://127.0.0.1:8000 **на весь екран** (тоді Trace буде праворуч).
4. Підготувати вкладки: `docs/REPORT.md` (найкраще на GitHub, там малюється діаграма), `AGENTS.md`, `.claude/skills/`, `docs/crisp_dm_log.md`.
5. Почати запис: **Win + Alt + R** або OBS.
